# Light Games

Маленькая коллекция HTML-игр. Открываются прямо в браузере, ничего ставить не надо.

## Играть

👉 **[tsybriki.github.io/light_games](https://tsybriki.github.io/light_games/)**

## Что внутри

| Игра | Файл | Описание |
|---|---|---|
| 🃏 Blackcheck | `blackjack.html` | Блэкджек против дилера |
| 🎴 UNO | `uno-game.html` | UNO против бота |

Все игры самодостаточны (один HTML-файл, без зависимостей), оптимизированы под мобильные и работают оффлайн после первой загрузки.

## Локальный запуск

```bash
git clone https://github.com/tsybriki/light_games.git
cd light_games
python3 -m http.server 8000
# открыть http://localhost:8000
```
